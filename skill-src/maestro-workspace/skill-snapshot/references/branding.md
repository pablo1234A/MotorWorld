# Branding e identidad visual

## Proceso
1. **Estrategia**: público, posicionamiento ("para X que necesitan Y, somos el único Z"), 3 adjetivos de personalidad y 3 que NO somos.
2. **Moodboard**: 12–20 referencias fuera del sector (arquitectura, moda, editorial).
3. **Logo**: debe funcionar a 16 px y en un color. Tipos: logotipo (tipográfico), símbolo + logotipo, monograma. Simplicidad > detalle.
4. **Sistema**: paleta (1 primario, 1 acento, neutros), 2 tipografías, iconografía, estilo fotográfico, tono de voz, retícula.
5. **Aplicaciones**: favicon, perfil de redes, tarjeta, web, packaging, plantillas de posts.

## Reglas de logo
- Diseña en negro primero; el color va después.
- Ajuste óptico, no matemático (las formas redondas sobresalen un poco).
- Versiones: horizontal, vertical, símbolo solo, positivo/negativo. Área de respeto = altura de una letra.
- Entrega en SVG + PNG transparente + PDF.
